※当記事は個人ブログに移行しました 最近ElasticMQというのを知りました。 Amazon SQS-compatible interface ということで、Amazon SQSを使ったアプリケーション開発が捗りそうです。 ちょうど試そうと思った今日(2016/11/23)にVersion 0.11.0になっていました。 java6以降が入ってれば動くようです。 今回はDockerで動かして、aws-cliで接続してみたいと思います。 Dockerfileの作成 FROM java:8 ADD https://s3-eu-west-1.amazonaws.com/softwaremill-public/elasticmq-server-0.11.0.jar /elasticmq/elasticmq-server-0.11.0.jar EXPOSE 9324 ENTRYPOINT ["java","-jar","/elasticmq/elasticmq-server-0.11.0.jar"] コンテナイメージのビルド $ docker build -t tsukapah/elasticmq:0.11.0 .
